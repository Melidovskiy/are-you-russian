Расширение и HTTP API

Расширение для Chrome и Chromium

Site Locale Control из исходного проекта позволяет выбрать часовой пояс, язык и форматы для конкретных сайтов, скрыть измерение отдельных шрифтов и фильтровать WebRTC-кандидаты. Системные настройки и выходной IP не меняются.

Скачать расширение

Распакуйте архив. Откройте chrome://extensions, включите режим разработчика, нажмите «Загрузить распакованное расширение» и выберите папку с manifest.json. Все изменения изначально выключены. Добавьте сайт и предоставьте доступ только ему. Для отмены используйте «Восстановить».

Глобальная политика WebRTC затрагивает все сайты и требует отдельного подтверждения. Подмена браузерных значений не гарантирует доступ к Claude.

Проверка из терминала

GET /api/check?format=json — российский профиль по Accept-Language и User-Agent. HTTP не видит часовой пояс, шрифты, Intl и WebRTC, поэтому ответ содержит покрытие и диапазон, а не полный браузерный результат.

GET /api/ip?format=json — IP отправителя, геоданные, репутация, вычеты и состояние каждого источника. Параметр ip игнорируется. Без format=json ответ текстовый. Поддерживаются GET и OPTIONS; ограничение — 30 запросов в минуту на IP для каждого endpoint.

Пример: curl -H "Accept-Language: ru-RU,ru" https://АДРЕС-САЙТА/api/check?format=json.

Как читать результаты

Согласованность часового пояса и языка

Смотрите название зоны и сезонные смещения вместе. Изменение только смещения Date без Intl оставляет противоречие. Аналогично, список navigator.languages и региональные форматы Intl — разные значения. Расширение позволяет менять их согласованно для выбранного сайта.

Что показывает WebRTC

host может быть локальным адресом или mDNS-именем, srflx — адресом, полученным через STUN, relay — адресом TURN. Локальный адрес сам по себе не доказывает утечку внешнего IP. Сравните публичный srflx с выходным адресом VPN. Отсутствие кандидатов не доказывает защиту во всех приложениях.

Репутация IP и доступ к Claude

Страна и ASN не определяют репутацию сами по себе. Источники могут расходиться или не иметь данных. Оценка IP использует отдельные штрафы оригинала, выбирая более строгие признаки. Ни низкий браузерный индекс, ни высокий балл репутации не являются гарантией доступа или безопасности аккаунта.

Claude Code и веб-версия

Этот сайт не читает установленный Claude Code, его системный промпт, аккаунт или историю. Браузерные измерения и серверные заголовки показывают только доступные данной странице признаки. Проверяйте ограничения и доступность по официальным источникам: поддерживаемые страны, статус сервисов, поддержка Claude.

Как это связано с Claude

Страница проверяет настройки, доступные веб-сайтам. Индекс использует российский профиль проекта FuckClaude. Сумма весов семи проверок — 100 баллов.

Низкий индекс — до 30 баллов, средний — от 31 до 60, высокий — от 61. Если часть данных недоступна, результат показан диапазоном.

Какие проверки использует Claude?

Публичные разборы Claude Code описывают чтение часового пояса и имени стороннего API-сервера. Российский профиль FuckClaude объединяет региональные признаки в авторскую модель. Её баллы отражают настройки браузера, а внутренние проверки Anthropic остаются неизвестны.

Исходный проект и описание методики

Почему VPN может давать высокий индекс?

VPN меняет маршрут и выходной IP. Часовой пояс, языки, шрифты и региональные форматы задаются в системе и браузере. Их значения видны в подробных результатах.

Куда отправляются результаты?

По нажатию «Начать проверку» сервер передаёт выходной IP сервисам proxycheck.io и AbuseIPDB, если настроены ключи, и ipwho.is для геоданных. При включённом WebRTC STUN-сервер Google также получает сетевой адрес запроса. Остальные измерения выполняются в браузере.

JSON и PNG создаются на устройстве. JSON содержит выходной IP и может включать адреса WebRTC. В PNG сохраняются баллы и тип сети. Сервер хранит результаты IP в памяти до 8 минут и счётчики ограничения запросов; при перезапуске они сбрасываются. Хостинг получает обычные сетевые запросы.
