Сначала установите, на каком этапе прерывается работа. Для сетевого сбоя, ограничения частоты запросов и ошибки авторизации нужны разные действия.

## Соединение не устанавливается

Ошибка разрешения имени указывает на этап DNS. Тайм-аут сообщает, что запрос не завершился за отведённое время. Он возможен на разных участках цепочки. Ошибка TLS относится к установлению защищённого соединения и требует проверки имени сервера, сертификата и времени устройства.

Сопоставьте ошибку с журналом клиента и состоянием прокси. Если проверка порта проходит, а запрос зависает, продолжите проверку на уровне TLS и передачи данных. Сам по себе пинг не устанавливает работоспособность VPN.

## Сервер вернул HTTP-ошибку

Для Claude API опубликованы следующие значения. Ответы веб-страниц, CDN и стороннего шлюза нужно читать с учётом того, какой сервер их выдал. [Описание ошибок API](https://platform.claude.com/docs/en/api/errors).

| Код | Что проверить |
| --- | --- |
| 401 | Авторизацию и действительность ключа |
| 403 | Доступ к запрошенному ресурсу и текст ответа |
| 429 | Лимиты и указанный срок повторного запроса |
| 529 | Перегрузку сервиса |

Смена IP не следует автоматически из HTTP-кода. Сначала прочитайте тип и сообщение ошибки. Для обращения к разработчику клиента полезен request ID, если он есть в ответе. Пароли, токены и cookies передавать не нужно.

## Веб-версия работает, Claude Code не подключается

Браузер и процесс Claude Code могут использовать разные параметры сети. Сравните активный прокси, разрешение имён и доступ к доменам, необходимым для входа и API. Открытая главная страница проверяет только часть этого пути. [Сетевая документация Claude Code](https://code.claude.com/docs/en/network-config).

При работе внутри Cage сначала смотрите его проверки среды и выхода. Успешное сканирование на основной системе описывает другую среду. [Раздел о Claude Cage](../claude-cage/).

## Ошибка появилась без изменения настроек

Проверьте состояние сервисов Claude и повторите тот же запрос через известное рабочее соединение. Сохраните время, сеть, клиент и точный текст ошибки. Такое сравнение помогает локализовать сбой. При подтверждённом ограничении аккаунта сетевые изменения не восстанавливают его состояние. [Статус сервисов Claude](https://status.claude.com/).
