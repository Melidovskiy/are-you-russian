Браузер передаёт страницам часть настроек устройства. В подробных результатах видны измеренные значения и то, как каждое из них повлияло на индекс.

## Часовой пояс и языки

Проверка читает название часового пояса, смещения UTC, список языков браузера и региональные форматы. Эти значения задаются разными настройками. Смена языка интерфейса может оставить прежними форматы дат и чисел.

Сравнивать часовой пояс с городом выходного IP полезно для проверки согласованности окружения. Само расхождение допускает обычные объяснения, например поездку или удалённую работу. В методике сайта это измеряемый признак, которому присвоен вес. [Описание исходной проверки](https://github.com/LinXiaoTao/FuckClaude).

## Шрифты и браузер

Страница проверяет доступность выбранных шрифтов и признаки браузера. Установленное приложение может добавить шрифт в систему, после чего он станет доступен другим приложениям. Значение в отчёте показывает результат конкретного измерения.

Узнать по одному шрифту, пользуется ли человек соответствующим сервисом, нельзя. Аналогично, User-Agent и Client Hints описывают заявленное окружение браузера. Изменения этих строк могут оставить другие признаки прежними.

Расширение из этого репозитория меняет отдельные значения для выбранных сайтов. Его область действия ограничена браузером. Claude Code, другое приложение и сетевой маршрут требуют собственной проверки.

## WebRTC и выходной IP

При включённой проверке WebRTC браузер обращается к STUN-серверу. Кандидат `host` может содержать локальный адрес или mDNS-имя. Публичный кандидат `srflx` имеет смысл сравнить с IP в основном отчёте.

Локальный адрес встречается в обычной работе WebRTC. Публичный адрес другой сети требует проверки маршрута. Если кандидатов нет, измерение остаётся неполным. Этот результат относится к данному браузеру и моменту проверки.

## Отдельное окружение

Для Claude полезно рассматривать браузер, терминал и сеть как связанную среду. Независимые изменения отдельных параметров увеличивают число настроек, которые приходится поддерживать и проверять.

В [Claude Cage](../claude-cage/) эти задачи объединены в изолированной среде. Документация проекта описывает отдельные региональные настройки, проксирование и проверки сети перед допуском трафика. Условия работы зависят от установленной версии и выбранного прокси. [Описание Claude Cage](https://github.com/Lee-xeo/Claude-Cage).
