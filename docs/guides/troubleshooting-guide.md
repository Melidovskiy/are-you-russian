## Начните с области сбоя

Определите, загружается ли сам сайт, проходит ли вход, отправляется ли запрос и приходит ли полный ответ. Сверьте время со страницей состояния Claude. Затем повторите минимальную попытку, сохранив журнал и выбранный маршрут.

## Если возникает Timeout

Проверьте DNS, установление соединения и передачу данных. Сравните домашнюю и мобильную сеть при одинаковых адресе, порте и протоколе. Затем проверьте IPv4 и IPv6, если клиентская сеть поддерживает оба семейства.

Успешный TCP-тест может сочетаться с отказом на следующем этапе. Для контрольного опыта нужна реальная HTTPS-загрузка. Запись на сервере помогает установить, дошли ли пакеты в момент конкретной попытки.

## Если получен HTTP-ответ

Для прямого Claude API официальная документация описывает следующие классы. У шлюза или страницы входа могут быть собственные тексты и коды, поэтому сначала установите отправителя ответа.

| Код | Что проверить |
| --- | --- |
| 400 | Содержимое запроса и указанную в сообщении причину |
| 401 | Аутентификацию и состояние ключа |
| 403 | Права на ресурс и параметры организации |
| 404 | Путь endpoint и идентификаторы |
| 429 | Тип ограничения и `retry-after` |
| 5xx, включая 529 | Состояние сервиса и возможность ограниченного повтора |

Сохраните тело ошибки и request ID. Один код 403 не описывает автоматически состояние транспорта, репутацию адреса или причину ограничения аккаунта.

## Если не работает вход

Проверьте активную почту, выбранный браузерный профиль и наличие нужного способа аутентификации. Сравните поведение с временным чистым профилем, сохраняя остальные условия. Cookies и расширения меняйте по одному, чтобы понимать влияние каждого действия.

Если показано сообщение об отключении аккаунта или организации, используйте соответствующий доступный запрос на проверку. Повторная сетевая диагностика полезна для самостоятельных сетевых симптомов.

## Что включить в отчёт

```text
Время и часовой пояс:
Устройство и версия клиента:
Сеть и режим маршрутизации:
Точный симптом:
HTTP-статус / тип ошибки / request ID:
Контрольное сравнение и результат:
```

Удалите из копии журнала ключи, токены подписок, UUID профилей и чувствительные тексты запросов. Для локализации ошибки важна воспроизводимая последовательность действий.
