## Установите источник настроек

Перед диагностикой запишите версию Claude Code и способ входа. Проверьте параметры проекта, личного профиля и организации. В официальной документации описаны уровни конфигурации и их приоритет — значение из одного файла может быть переопределено другим уровнем.

Параметры браузера не показывают автоматически окружение CLI. Проверьте тот же терминал, контейнер или удалённую машину, откуда запускается клиент. Для отчёта достаточно версии, названия способа аутентификации и обезличенного описания маршрута.

## Проверьте LLM-шлюз

Если организация использует собственный шлюз, начните с его официальной инструкции подключения. Уточните поддерживаемые методы аутентификации, модели, streaming и передачу служебных заголовков. Для Claude Code совместимость включает больше, чем успешный одиночный запрос.

Сохраните hostname и путь endpoint, скрыв секреты и параметры с токенами. Проверьте, кто управляет TLS-сертификатом и журналами шлюза. Оператор шлюза может обрабатывать запросы и ответы, поэтому до передачи рабочего контекста согласуйте этот маршрут с владельцем данных.

В исходных материалах FuckClaude встречаются советы с внутренними переменными клиента. Для воспроизводимой конфигурации предпочтительны параметры, описанные в документации установленной версии. Если проверяете внутренний переключатель, фиксируйте точную версию и результат опыта.

## Храните ключи вне исходного кода

Используйте переменные окружения или подходящее хранилище секретов. В репозитории оставляйте только образец с пустыми значениями. Перед публикацией проверьте также историю Git, журналы CI, архивы, скриншоты и собранные файлы.

Удаление ключа из последней версии файла оставляет предыдущие коммиты доступными. При подтверждённой утечке отзовите ключ у поставщика и создайте замену по его процедуре. После этого обновите конфигурацию и проверьте старые развёртывания.

## Подготовьте диагностику

Сохраните HTTP-статус, тип ошибки и request ID. Сравните запрос через шлюз с разрешённым контрольным маршрутом, если он у вас есть. Оставляйте одинаковыми модель и содержимое минимального теста.

Для обращений достаточно обезличенного фрагмента конфигурации и последовательности действий. Значения ключей, cookies и закрытые тексты запросов удаляйте из копии отчёта.
