О методике

Четыре проверки дают до 100 баллов. Индекс описывает совпадения с российским профилем. WebRTC, IPv4, IPv6 и репутация IP показаны отдельно.

Как читать баллы

До 30 баллов — низкий индекс, от 31 до 60 — средний, от 61 — высокий. Меньшее значение означает меньше совпадений. Недоступные измерения расширяют диапазон результата.

Для репутации IP более высокий балл означает лучшую оценку по доступным источникам. Состояние каждого источника указано в отчёте.

Исходный проект и методика

Какие данные передаются

По нажатию кнопки проверки сервер передаёт выходной IP в proxycheck.io и AbuseIPDB, если настроены ключи, и в ipwho.is для геоданных. По выбору пользователя браузер обращается к STUN-серверу Google для WebRTC и к ipify для раздельной проверки IPv4 и IPv6.

JSON и PNG создаются на устройстве. В отчёт могут попасть IP-адреса. Сервер хранит результаты репутации IP в памяти до 8 минут и счётчики запросов. Хостинг может вести журналы доступа. Сайт запоминает только выбранную тему.

Инструменты проекта

Расширение для отдельных настроек браузера и HTTP API для проверки доступных серверу признаков.

Расширение для Chromium

Расширение позволяет менять часовой пояс, язык, форматы и доступность отдельных шрифтов для выбранных сайтов. Системные приложения и выходной IP имеют собственные настройки.

Распакуйте ZIP, откройте chrome://extensions, включите режим разработчика и загрузите папку с manifest.json. Все изменения изначально выключены. Доступ к сайту и глобальная политика WebRTC запрашиваются отдельно.

HTTP API

GET /api/check?format=json возвращает доступные серверу признаки по Accept-Language и User-Agent.

GET /api/ip?format=json возвращает IP отправителя, геоданные, репутацию и состояние источников. Параметр ip игнорируется. Ограничение — 30 запросов в минуту на IP для каждого маршрута.
