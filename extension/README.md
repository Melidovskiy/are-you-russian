# Расширение Are you Russian

Site Locale Control из FuckClaude, адаптированный для российского профиля. Лицензия MIT, автор исходного проекта LinXiaoTao.

Настройки по умолчанию выключены. Добавьте HTTPS-сайт, предоставьте доступ и включите нужные изменения. Можно согласованно изменить часовой пояс и смещение, язык и Intl, фильтрацию измерений шрифтов и WebRTC, профиль User-Agent. Кнопка восстановления удаляет собственные изменения расширения. Системные настройки и IP не меняются.

Глобальная политика WebRTC запрашивается и подтверждается отдельно; она действует на все сайты браузера. Подмена значений не гарантирует доступ к Claude.

```sh
npm ci
npm test
npm run typecheck
npm run build
```

Готовая папка: `.output/chrome-mv3`. Установка: chrome://extensions → режим разработчика → загрузить распакованное расширение. Сборка ZIP из корня проекта: `npm run extension:build`.

Интеграционная проверка: `npm run e2e`. Требуется Chrome for Testing, устанавливаемый через `npx puppeteer browsers install chrome`, либо переменная `CHROME_PATH`. Используется отдельный временный профиль; личные настройки браузера не затрагиваются.
