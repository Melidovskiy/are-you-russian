## Откуда взялась методика

Исходный FuckClaude ссылается на публичные разборы Claude Code, в которых описывались чтение часового пояса и анализ имени стороннего API-хоста. Авторы разбора связывали результаты с изменением символов в строке даты системного промпта. Подробности такого поведения зависят от исследованной версии клиента.

В этой адаптации ссылка ведёт на исходный проект и закреплённую версию кода. Российский профиль объединяет доступные браузеру признаки в модель диагностики. Утверждение о конкретной внутренней проверке следует проверять по воспроизводимому разбору соответствующей версии Claude Code.

## Какие сведения доступны странице

| Признак | Что измеряет сайт |
| --- | --- |
| Часовой пояс | Название зоны и смещения Date/Intl |
| Языки | Порядок значений `navigator.languages` |
| Шрифты | Изменение метрик при подстановке известных семейств |
| WebRTC | Доступные ICE-кандидаты при включённом тесте |
| Браузер | User-Agent и доступные Client Hints |
| Региональные форматы | Параметры Intl и примеры форматирования |

Для российского профиля сумма весов равна 100. Отдельный вклад округляется перед сложением. Если данные недоступны, итог представлен диапазоном. Эта неопределённость полезнее нулевого вклада за непроведённую проверку.

## Как сопоставлять уровни наблюдений

Настройки устройства, репутация IP, состояние аккаунта, платёж и HTTP-ответ описывают разные части ситуации. Сканирование страницы охватывает первые два пункта в пределах доступных данных. Для остальных нужны сведения из соответствующего кабинета или ответа сервера.

Один признак редко позволяет восстановить весь путь принятия решения. Например, шрифт может появиться после установки приложения, а часовой пояс может быть задан расширением только для одного сайта.

## Как проверять техническое утверждение

Сохраните версию клиента, источник исходного кода, параметры запуска и минимальный пример. Отдельно запишите наблюдаемый результат и вывод автора. Для рассказа о скрытых маркерах нужны сами байты или воспроизводимое извлечение, а для причин блокировки — дополнительные сведения от сервиса.

При обновлении Claude Code повторяйте измерение. Непубличные переменные окружения и советы из старого разбора могут изменить смысл или прекратить работу.
