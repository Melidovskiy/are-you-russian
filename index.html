Как это связано с Claude

Оригинальный FuckClaude появился после сообщений об анализе Claude Code. При работе через сторонний API-адрес клиент проверял часовой пояс и имя прокси, а результат кодировал в строке даты системного промпта.

В исходном коде подтверждённой проверкой Claude Code отмечен китайский часовой пояс. Для России автор составил отдельный оценочный профиль. Здесь используются его детекторы, веса и пороги.

Этот сайт показывает браузерную часть окружения. Доступ к внутренней оценке Anthropic, данным аккаунта и настройкам установленного Claude Code у страницы отсутствует. Итоговые баллы помогают разобрать доступные признаки, но точную вероятность блокировки по ним определить нельзя.

Исходный проект и описание методики

Из чего складывается оценка?

Часовой пояс — 34 балла, языки — 22, шрифты приложений — 12, WebRTC — 10, браузер — 10, региональные форматы — 8, платформа и стиль emoji — 4. Это веса автора исходного проекта. Максимальная сумма — 100. Пороги низкого, среднего и высокого индекса также сохранены из FuckClaude.

Без проверки WebRTC или при недоступных данных показывается диапазон. Например, 45–55 означает 45 полученных баллов и ещё 10 баллов непроверенного сигнала.

Можно ли узнать регион по одному признаку?

Русский язык, шрифты и выбранный часовой пояс встречаются у людей в разных странах. WebRTC сам по себе не определяет Россию, а тип платформы имеет слабую связь с регионом. Эти ограничения есть у исходной методики. Сервер Claude дополнительно получает IP и данные аккаунта, которые в этой оценке не учитываются.

Что происходит с моими данными?

Проверки выполняются в браузере. Аналитики и сохранения результатов между посещениями нет. Шрифты загружаются с самого сайта. Хостинг получает обычные запросы загрузки страницы.

WebRTC включается отдельным флажком перед запуском и обращается к STUN-серверу Google. Отчёт формируется на устройстве и может содержать адреса из WebRTC. Проверьте его содержимое перед отправкой другим людям.
